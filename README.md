# ExamIntel Research Engine

An AI agent skill that converts uploaded examination question papers into
comprehensive, research-backed study material written in simple, natural,
human-written English.

---

## What It Does

You give it a question paper. It gives you back:

- **Model answers** calibrated to the exact mark scheme (2-mark answers are
  tight, 10-mark answers have depth and diagrams)
- **Topic notes** organized by syllabus chapters, not just the questions asked
- **Previous year analysis** with question frequency tables and trend predictions
- **Question banks** with additional probable questions and concise answers
- **Quick revision sheets** with bullet points, mnemonics, and key formulas

Everything reads like it was written by an experienced college teacher — not
generated by AI.

## Installation

Copy the skill folder to your Gemini skills directory:

```
# The skill directory
C:\Users\<username>\.gemini\config\skills\examintel-research-engine\

# Verify SKILL.md exists at:
C:\Users\<username>\.gemini\config\skills\examintel-research-engine\SKILL.md
```

The skill is auto-discovered by any Gemini-compatible agent once the folder
is in place. No additional configuration needed.

## Supported Input Formats

| Format | How It's Processed |
|--------|--------------------|
| **PDF** | Parsed with PDF text extraction; falls back to OCR for scanned papers |
| **Image** (PNG, JPG, JPEG, TIFF) | Processed with OCR or vision model |
| **Text** (plain text, Markdown) | Used directly — no extraction needed |
| **Pasted text** | User pastes questions directly into the chat |

> For best results, upload clear, high-resolution files. Blurry scans or
> photos taken at an angle will produce poor extraction results.

---

## Output Formats

| Format | Description |
|--------|-------------|
| **Markdown** (`.md`) | Always generated. Editable, portable, viewable anywhere. |
| **PDF** (`.pdf`) | Print-ready study material. Requires PDF libraries on the system. |
| **HTML** (`.html`) | Web-viewable with styling. Good for sharing digitally. |
| **JSON** (`.json`) | Structured data: question banks, frequency tables, metadata. |
| **CSV** (`.csv`) | Tabular exports: topic mapping, PYQ frequency, marks distribution. |

## Known Limitations

1. **OCR accuracy depends on input quality.** Handwritten papers, low-resolution
   scans, and skewed images will produce errors. Clear, typed papers work best.

2. **Syllabus matching is best-effort.** The skill searches for syllabi online
   and from known patterns. If your university's syllabus isn't findable, you
   may need to provide it manually.

3. **Previous year papers require internet access.** Without web search, PYQ
   analysis relies on whatever papers you upload manually.

4. **PDF generation requires system libraries.** If WeasyPrint, pdfkit, or
   equivalent tools aren't installed, output falls back to Markdown + HTML.

5. **Diagram generation is capability-dependent.** Without matplotlib or image
   tools, diagrams are rendered as text-based alternatives (ASCII or Mermaid
   code blocks).

6. **Language is English only.** The skill does not support generating study
   material in other languages at this time.

7. **Mark schemes vary.** The mark-wise length guidelines are based on common
   Indian university patterns. Adjust if your institution uses a different
   marking convention.
