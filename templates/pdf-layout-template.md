# PDF Layout Specification

Professional formatting rules for generating print-ready academic study material PDFs.

---

## Page Setup

| Property | Value |
|----------|-------|
| Page Size | A4 Portrait (210mm × 297mm) |
| Top Margin | 20mm |
| Bottom Margin | 20mm |
| Left Margin | 18mm |
| Right Margin | 18mm |
| Content Width | 174mm |

---

## Title Page Layout

```
┌──────────────────────────────────────┐
│                                      │
│          [University Name]           │  ← 18pt, Navy, Bold
│          [University Logo area]      │
│                                      │
│     ─────────────────────────────    │
│                                      │
│      [Course Name] - [Semester]      │  ← 14pt, Slate Blue
│                                      │
│      [Subject Name]                  │  ← 24pt, Navy, Bold
│      [Subject Code]                  │  ← 12pt, Gray
│                                      │
│     ─────────────────────────────    │
│                                      │
│  Examination-Ready Study Material    │  ← 11pt, Regular
│  Based on [Exam Year] [Session]      │
│                                      │
│      Generated: [Date]               │  ← 10pt, Gray
│                                      │
└──────────────────────────────────────┘
```

**Rules:**
- No promotional QR codes, personal links, or advertisements
- No author branding beyond "Generated by ExamIntel Research Engine"
- Clean, professional academic appearance

## Heading Hierarchy

```
H1: Unit Title (Navy, 22pt, bold, top border line)
  H2: Topic Title (Slate Blue, 16pt, bold)
    H3: Subtopic (Dark Slate, 13pt, semibold)
      H4: Sub-section (11pt, semibold)
        Body text (10.5pt, regular)
```

**Rules:**
- Always maintain heading hierarchy (never skip levels)
- H1 always starts on a new page
- H2 must have at least 3 lines of content visible before a page break
- Never orphan a heading at the bottom of a page

---

## Table of Contents

- Auto-generated from H1 and H2 headings
- Include page numbers
- Maximum depth: 2 levels (H1 + H2)
- Dotted leaders connecting title to page number
- Placed on page 2 after title page

## Page Headers and Footers

**Header (all pages except title):**
```

```

**Footer:**
```
─────────────────────────────────────────────────────
Left: ExamIntel Study Material     Center: Page X     Right: [Course] [Semester]
```

---

## Page Break Rules

| Situation | Rule |
|-----------|------|
| New Unit (H1) | Always start on new page |
| Heading at page bottom | Move heading to next page if fewer than 3 lines fit below |
| Table split | Repeat table header row on continuation page |
| Code block | Do not split code blocks across pages if under 20 lines |
| Diagram | Keep diagram and caption together on same page |
| List | Do not split list if 4 or fewer items |

---

## Table Formatting

- Header row: Navy background, white text, bold
- Alternate row shading: every even row in Light Blue
- Border: 0.5pt solid `#CBD5E1`
- Cell padding: 4pt horizontal, 3pt vertical
- Text alignment: left for text columns, center for numbers
- Maximum table width: 100% of content area
- If table exceeds page width: reduce font to 8.5pt or rotate to landscape

---

## Code Block Formatting

- Background: `#F1F5F9`
- Border: 1pt solid `#E2E8F0`
- Border radius: 4pt
- Padding: 8pt
- Font: Fira Code or Consolas, 9.5pt
- Syntax highlighting: language-appropriate colors
- Line numbers: include for blocks over 10 lines

---

## Diagram Placement

- Center diagrams horizontally
- Include caption below: "Figure X: Description"
- Caption in italic, 9pt
- Minimum 6pt spacing above and below diagrams
- Maximum diagram width: 85% of content area
- Keep diagram and caption on the same page

## Print-Ready Specifications

- Resolution: 300 DPI minimum for all embedded images
- Color mode: CMYK-safe colors (the hex palette above is CMYK-compatible)
- Bleed: Not required for standard academic printing
- File size: Optimize images to keep PDF under 15MB per 100 pages
- Font embedding: Embed all fonts for cross-platform rendering
