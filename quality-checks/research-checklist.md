# Research Quality Checklist

Run this checklist after completing university identification, syllabus research, and previous year paper research.

---

## University Identification

- [ ] University name matches the paper header exactly
- [ ] University verified through at least one official source (website, UGC list)
- [ ] University type correctly identified (State / Central / Private / Deemed)
- [ ] Affiliated board or regulatory body identified if applicable
- [ ] Confidence level assigned (High / Medium / Low) with justification
- [ ] If identification is uncertain, ambiguity is explicitly stated

## Syllabus Verification

- [ ] Syllabus source is from the official university website or verified academic portal
- [ ] If from an unofficial source, it is marked as "unverified"
- [ ] Syllabus year matches or is closest to the examination year
- [ ] Any known syllabus changes between years are noted
- [ ] Unit-wise topic breakdown is complete
- [ ] Prescribed textbooks are listed with author and edition
- [ ] Exam questions are mapped to syllabus units
- [ ] Coverage gaps (questions outside syllabus) are identified
- [ ] Source URL is recorded

## Previous Year Paper Research

- [ ] Previous papers are from verified sources with URLs
- [ ] Paper year, session, and university are confirmed for each
- [ ] No fabricated paper references exist in the data
- [ ] No invented examination years or sessions
- [ ] Papers from the same university are prioritized
- [ ] Papers from comparable universities are clearly labeled as such
- [ ] Total number of papers found is honestly reported
- [ ] Papers that were searched for but not found are listed
- [ ] Question extraction from previous papers follows the same extraction checklist

## Source Integrity

- [ ] Every source has a recorded URL or document reference
- [ ] Source verification status is assigned (Verified / Unverified / Unavailable)
- [ ] No copy-pasted content without attribution
- [ ] Conflicting information from different sources is flagged with explanation
- [ ] At least 2 sources used for important factual claims where possible

## Capability Transparency

- [ ] If internet was unavailable, this is clearly stated
- [ ] If OCR was unavailable, limitations on scanned document processing are noted
- [ ] Research depth is honestly characterized (Comprehensive / Partial / Minimal)
- [ ] Any areas where more research would be beneficial are identified

## Honesty Rules

**NEVER do any of the following:**
- Invent a previous year paper that doesn't exist
- Fabricate an examination year or session
- Claim a question appeared in a specific year without evidence
- Pretend internet research was done when it was not
- Mark an unverified source as verified
- Generate a fake URL or source reference
- Claim 100% syllabus coverage when gaps exist

---

## When a Check Fails

| Failure | Action |
|---------|--------|
| University cannot be identified | Mark as "Unidentified" and proceed with available info |
| Official syllabus not found | Use best available source, mark as "Inferred Syllabus" |
| No previous papers found | Honestly report "No previous papers available for research" |
| Source URL is broken | Note the broken URL, attempt alternative sources |
| Conflicting information | Present both versions with sources, recommend the official one |

---

## Completion Criteria

Research is complete when:
1. University identification has a confidence level
2. Syllabus has a verification status
3. Previous paper search has been attempted honestly
4. All sources are recorded with verification status
5. All limitations are disclosed in the research report
