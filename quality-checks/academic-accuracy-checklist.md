# Academic Accuracy Checklist

Verify all generated answers and study notes for academic correctness.

---

## Answer Completeness

- [ ] Every question from the original paper has an answer
- [ ] Every sub-question has its own answer (not merged)
- [ ] No question was silently skipped
- [ ] Internal choice questions all have answers

## Mark Calibration

- [ ] 1-2 mark answers are concise (under 50 words)
- [ ] 3-5 mark answers are structured (80-180 words)
- [ ] 10-15 mark answers are comprehensive (300-550 words)
- [ ] Answer depth matches what an examiner would expect for the marks
- [ ] No short answer is unnecessarily padded
- [ ] No long answer is superficially thin

## Factual Accuracy

- [ ] Definitions are technically correct
- [ ] Dates, names, and historical facts are accurate
- [ ] Mathematical formulas are correct
- [ ] Code snippets compile and run correctly (or are noted as pseudocode)
- [ ] Algorithm steps are in the correct order
- [ ] Complexity analysis values are correct (Big-O notation)
- [ ] No contradictory statements within the material

## Numerical Accuracy

- [ ] Given values are correctly transcribed from the question
- [ ] Correct formula is applied
- [ ] Substitution is mathematically correct
- [ ] Step-by-step calculation is verifiable
- [ ] Final answer includes correct units
- [ ] Decimal precision is appropriate
- [ ] Verification step confirms the answer where possible

## Diagram Accuracy

- [ ] Diagram labels match the text explanation
- [ ] Diagram components are correctly placed (e.g., BST property holds)
- [ ] Arrows / flow direction is correct
- [ ] No missing components in structural diagrams
- [ ] Caption accurately describes the diagram

## Syllabus Coverage

- [ ] All relevant syllabus units are covered in the notes
- [ ] No major topic is missing from the study material
- [ ] Related prerequisite concepts are explained
- [ ] Topic depth matches examination importance

## Question Bank Integrity

- [ ] Original paper questions are correctly categorized as "A"
- [ ] Verified PYQs are categorized as "B" with year evidence
- [ ] AI-generated questions are NEVER labeled as previous year questions
- [ ] Category labels are honest and accurate
- [ ] Marks suggestions are reasonable for the question difficulty

---

## When a Check Fails

| Failure | Action |
|---------|--------|
| Missing answer | Generate the answer immediately |
| Wrong formula | Correct and re-derive |
| Code doesn't work | Fix syntax, test logic, add comments |
| Mark calibration off | Adjust answer length and depth |
| Diagram error | Redraw with correct information |
| Incorrect fact | Research and correct with source |
